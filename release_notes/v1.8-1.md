## 🎛️ Timbre Studio Audiophile Suite (v1.8-1)

Welcome to **Timbre v1.8-1**, a milestone release introducing the complete **Timbre Studio** audiophile suite, true bit-exact hardware routing, concurrent predictive FLAC pre-warming, and major cache engine optimizations.

---

### 🌟 Timbre Studio: All Features & Options Explained

- **🛡️ Bit-Exact Certification Badge**: Live signal-path verification indicator located at the top of the Audio Pipeline inspector.
  - `🟢 BIT-PERFECT: Bit-Exact Signal Path`: Confirms audio bypasses Android's system mixer (`AudioFlinger`) and reaches your hardware DAC unresampled at its native bit depth and sample rate.
  - `🟡 Framework Mixed (A2DP)` / `AudioFlinger`: Indicates when audio is being routed through Android's system or Bluetooth mixer.
- **📶 Bluetooth Codec Telemetry**: Real-time detection and display of active negotiated Bluetooth A2DP codecs (`LDAC`, `aptX Adaptive`, `aptX HD`, `aptX`, `AAC`, `SBC`) with exact negotiated transmission bit depth and sample rate (e.g. 24-bit / 96kHz for LDAC at 990 kbps).
- **🔌 Direct Bit-Perfect Mode (USB DAC Passthrough)**: Requests Android OS hardware USB host permissions via `UsbManager.requestPermission` for attached external USB DACs and Type-C DSP earphones (e.g., Fiio KA11/KA13/KA17, Moondrop Dawn Pro, Moondrop Chu II DSP, Apple USB-C Dongle). Bypasses Android's 48kHz resampler completely.
- **💎 Purist Mode ("Lossless or Nothing")**: Strict audiophile gatekeeper. When enabled, Timbre strictly refuses lossy YouTube audio fallback (128–160 kbps Opus/AAC). If a studio FLAC master stream cannot be resolved within the Priority Resolution Window across edge workers and addons, Timbre automatically skips past the unplayable track to the next song instead of ever degrading your listening experience with lossy audio.
- **⏱️ Priority Resolution Window (0.5s – 8.0s)**: Customizable slider controlling how long Timbre waits for Cloudflare edge workers and lossless addons to match and return a 24-bit FLAC stream before proceeding. Range now expanded up to **8.0 seconds** (0.1s increments) to give edge workers ample time for deeper catalog searches.
- **🧠 Audio Buffer Sizing**: Multi-tier internal memory buffer control for the AndroidX Media3 `AudioTrack` PCM sink:
  - `Low Latency (~250ms)`: Ultra-fast tactile response to seeks and pause/resume.
  - `Standard (~500ms)`: Optimal balance of latency and playback stability.
  - `Audiophile Stable (~1500ms)`: Deep PCM buffer immune to micro-stutters during Android backgrounding or heavy Doze power-saving.
- **🔄 Bit-Perfect Rate Switching**: Dynamically reconfigures the hardware `AudioTrack` sink on the fly to match each track's native container sample rate (`44.1 kHz`, `48 kHz`, `88.2 kHz`, `96 kHz`, `176.4 kHz`, `192 kHz`), eliminating non-integer sample rate conversion jitter.
- **⏩ Queue Lookahead Engine (3 to 20 Tracks)**: Configurable lookahead buffer that resolves upcoming tracks in parallel over the network. Rapid skipping no longer cancels in-flight jobs.
- **📡 Lossless Pre-warming Network Mode**: Multi-state selector (`Off`, `Wi-Fi Only`, `Any Network`) controlling background audio pre-caching to preserve mobile data.
- **💾 Pre-cached Songs Count (3 to 50 Songs)**: Configurable slider determining how many upcoming tracks have their audio bytes pulled and verified into disk cache ahead of the playhead.
- **⚖️ FLAC Dynamic Normalisation**: Multi-tier volume safeguard (`Off`, `Preserve Dynamics`, `EBU R128 Peak Safeguard`) preventing jarring volume spikes without compressing acoustic dynamics.
- **📊 Live Decoded PCM Telemetry (Stats for Nerds)**: Real-time overlay showing genuine physical data rate (e.g. 1,411 kbps for 16/44.1, 4,608 kbps for 24/96, 9,216 kbps for 24/192) alongside active server, container format, and buffer health.
- **☁️ Cloudflare Edge Health & Latency Monitor**: Real-time round-trip ping measurement embedded directly inside Settings.

### 🚀 Major Fixes & Performance Enhancements in v1.8-1

1. **True FLAC Background Disk Caching**:
   - Fixed cache key alignment in `AudioCache.kt` where lock probes previously queried bare `videoId` instead of `#alt-noatmos`, which had caused pre-caching lock probes to evaluate to 0 bytes and abort. Upcoming tracks now pre-cache their opening 1 MB and full stream chunks onto disk.
2. **Concurrent, Non-Destructive Lookahead**:
   - Replaced monolithic sequential job cancellation with concurrent, non-destructive per-track pre-warming. Rapid skipping no longer cancels in-flight lookahead jobs, eliminating delays when skipping through playlists.
3. **Lossless Cache Retention**:
   - Added `Origin.LOSSLESS` so cached FLAC tracks stay permanently on disk according to your LRU cache limit and appear cleanly in the Library's *Cached songs* folder.
4. **Instant Priority Window Fallback Race**:
   - Eliminated the 2–3s YouTube resolution stall after the priority window expires: Timbre now races the lossless search against YouTube, playing lossless immediately if ready.
5. **Light Mode UI Tuning**:
   - Re-engineered `SegmentedControl` selectors for Audio Buffer Sizing and Lossless Pre-warming to adapt dynamically to light mode with a soft light-gray track, elevated pure-white active pill, and sharp high-contrast typography.
6. **Player Badge Vertical Alignment**:
   - Fixed vertical clearance on the frosted glass Hi-Res pill badge under the seekbar, eliminating text clipping.
7. **CI Hardcoded Secret Security Fix**:
   - Cleaned up `.github/workflows/build-and-release.yml` by removing hardcoded token fallback, resolving the GitHub Actions security alert.
